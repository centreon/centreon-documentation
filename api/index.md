Every Centreon REST API in one place, with the same layout for all products and versions: endpoints grouped by topic, parameters, request and response schemas, and ready-to-copy code samples (curl, Python, Go, JavaScript…).

| API | Version | What it covers |
|:----|:--------|:---------------|
| [Centreon Web REST API](./centreon-web/centreon-web-restapi.info.mdx) | 26.10 | Configuration (hosts, services, templates, notifications…), monitoring (resource status, acknowledgements, downtimes), administration and authentication of Centreon Infra Monitoring OnPrem. |
| [Centreon Web REST API](./centreon-web/25.10/centreon-web-restapi.info.mdx) | 25.10 | The same API, for platforms running version 25.10. |

| [Centreon MAP API](./centreon-map/centreon-map-api.info.mdx) | 26.10 | Maps, views and their content in Centreon MAP. |
