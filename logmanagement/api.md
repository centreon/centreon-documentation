## CLM API

Centreon Log Management provides a RESTful API to interact with logs, alerts, and product configuration.

The full and interactive API documentation is available here:

[View the Centreon Log Management API documentation](https://docs-api.centreon.com/api/centreon-log-management/)

You will find:
- A description of all available endpoints
- Authentication methods
- Example requests and responses
- A tool to test API calls directly from the interface

> This API is intended for developers and integrators who want to automate or extend Centreon Log Management features.
