Centreon Log Management provides a REST API to interact with logs, alerts, and product configuration. This API is intended for developers and integrators who want to automate or extend Centreon Log Management.

The full, interactive API documentation is available here: [Centreon Log Management API documentation](https://docs-api.centreon.com/api/centreon-log-management/).

You will find:
- A description of all available endpoints
- Authentication methods
- Example requests and responses
- A built-in tool to test API calls directly from the interface.
