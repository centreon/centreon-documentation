Centreon Log Management provides a REST API to interact with logs, alerts, and product configuration. This API is intended for developers and integrators who want to automate or extend Centreon Log Management.

Start with [Get started](/api/reference/log-management/centreon-log-management-api.info.mdx): how to create a token and make your first request. The API reference, in this section, then gives for each endpoint:

- its parameters, and the schemas of its request and responses
- code samples, in several languages
- a request panel, to send requests to the API from the page.
