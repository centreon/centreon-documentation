An unattended installation lets you install a central server by passing all the required settings as options to the installation script. The script then runs the whole procedure, including the web installation, without further input.

This is useful when you need to install several central servers with identical settings, when you install from a deployment tool or a CI pipeline, or when you have no interactive access to the target machine.

> An unattended installation always sets up the central server with a local database. To use a remote database, [install the central server from packages](using-packages.md).

## Options

To display the full list of options, run:

```shell
bash /tmp/unattended.sh -h
```

The main options are the following:

| Option | Description |
|--------|-------------|
| `-t <type>` | Type of server to install. Use `central` to install a central server. |
| `-d <database>` | Database to install. By default, the script installs MariaDB: use `-d MySQL` to install MySQL instead. |
| `--tls enabled` | Installs the central server in TLS mode: the connections to the web interface and to the database are encrypted. Without this option, the central server is installed without TLS. |
| `-p <password>` | Password of the default **admin** account. If you omit this option, the script generates a password and tells you where it is stored. |
| `-s` | Silent installation: the script does not prompt you for anything. |
| `-l <level>` | Level of detail of the log file: `DEBUG`, `INFO`, `WARN` or `ERROR`. |
