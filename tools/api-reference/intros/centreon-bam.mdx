## Get started in 3 steps

### 1. Find your API URL

The BAM API is served by your Centreon platform, with the rest of the Centreon REST API. Endpoints are relative to:

```text
{{baseUrl}}
```

:::tip Use your platform in this reference

Enter its address in [Set up this reference](#configure), below: the request panel and the code samples of every endpoint page then use it.

:::

### 2. Get a token

Create an **API token** in **Administration > Authentication tokens** (see [Authentication tokens]({{tokensDoc}})). It belongs to a user and stays valid until it expires or is revoked. The same token works with the Centreon Web REST API.

### 3. Call the API

Send the token in the `X-AUTH-TOKEN` header of every request. For example, to list your business activities with their real-time status:

```bash
curl -s "{{baseUrl}}/api/latest/bam/monitoring/business-activities" \
  -H "X-AUTH-TOKEN: <token>"
```

Each call runs with the rights of the user the token belongs to.

## Errors

An error returns an HTTP status code and a JSON body with a `code` and a `message`. The most common: `400` (invalid request), `401` (missing or expired token), `403` (insufficient rights), `404` (resource not found).
