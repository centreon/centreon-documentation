## Get started in 3 steps

### 1. Find your API URL

The MAP API is served by the MAP server:

```text
https://<map-server>:9443/centreon-map/api/latest
```

Without TLS, use `http://<map-server>:8081/centreon-map/api/latest`.

:::tip Use your MAP server in this reference

Enter its address in [Set up this reference](#configure), below: the request panel and the code samples of every endpoint page then use it.

:::

### 2. Get a token

Sign in with a Centreon user. Every MAP call also needs the `X-Client-Version` header, set to the version of your MAP server:

```bash
curl -s -X POST "https://<map-server>:9443/centreon-map/api/latest/auth/sign-in" \
  -H "Content-Type: application/json" \
  -H "X-Client-Version: 26.10.0" \
  -d '{"login": "<login>", "password": "<password>"}'
```

The response holds a `jwtToken`. You can also use a Centreon [API token](/docs/api/authentication-tokens) instead.

### 3. Call the API

Send the token in the `Authorization` header (or a Centreon API token in `X-AUTH-TOKEN`). For example, to list the maps:

```bash
curl -s "https://<map-server>:9443/centreon-map/api/latest/maps" \
  -H "X-Client-Version: 26.10.0" \
  -H "Authorization: Bearer <jwtToken>"
```

Each call runs with the rights of the user: map creation rights, and edition rights on the maps you change.

## Set up this reference {#configure}

Enter the address of your MAP server, and your token to send requests from this reference with **Send API Request**. The request panel and the code samples of every endpoint page use them until you close this browser tab. You can also change them on any endpoint page, with **Edit** next to the base URL.
