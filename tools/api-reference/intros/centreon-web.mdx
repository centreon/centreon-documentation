## Get started in 3 steps

### 1. Find your API URL

Every endpoint of this reference is relative to the same base URL:

```text
https://<your-centreon-server>/centreon/api/latest
```

`latest` targets the most recent API version of your platform. To pin a version, replace it with `v{{version}}`.

:::tip Use your platform in this reference

Enter its address in [Set up this reference](#configure), below: the request panel and the code samples of every endpoint page then use it.

:::

### 2. Get a token

For scripts and integrations, create an **API token** in **Administration > Authentication tokens** (see [Authentication tokens](/docs/api/authentication-tokens)). It belongs to a user and stays valid until it expires or is revoked.

To test quickly, you can also log in with a user's credentials:

```bash
curl -s -X POST "https://<your-centreon-server>/centreon/api/latest/login" \
  -H "Content-Type: application/json" \
  -d '{"security": {"credentials": {"login": "<login>", "password": "<password>"}}}'
```

The response holds the token in `security.token`. A token obtained this way expires after one hour without use.

### 3. Call the API

Send the token in the `X-AUTH-TOKEN` header of every request. For example, to list 20 hosts with their status:

```bash
curl -s "https://<your-centreon-server>/centreon/api/latest/monitoring/hosts?limit=20" \
  -H "X-AUTH-TOKEN: <token>"
```

Each call runs with the rights of the user the token belongs to.

## Filter, sort and paginate

Listing endpoints share the same query parameters:

| Parameter | Use | Example |
|:----------|:----|:--------|
| `limit` | Number of items per page (10 by default) | `limit=50` |
| `page` | Page to return, starting at 1 | `page=2` |
| `search` | Filter, in JSON | `search={"host.name":{"$lk":"srv-%"}}` |
| `sort_by` | Sort, in JSON | `sort_by={"host.name":"ASC"}` |

`search` supports the operators `$eq`, `$neq`, `$lt`, `$le`, `$gt`, `$ge`, `$lk` (like, with `%` as a wildcard), `$nk`, `$in`, `$ni` and `$rg` (regular expression), combined with `$and` and `$or`. URL-encode its value.

Listings return the items in `result` and the pagination in `meta` (`page`, `limit`, `total`). Dates use the ISO 8601 format.

## Errors

An error returns an HTTP status code and a JSON body with a `code` and a `message`. The most common: `400` (invalid request), `401` (missing or expired token), `403` (insufficient rights), `404` (resource not found).
