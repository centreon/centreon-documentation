## January 29th, 2026

Features

- [User journeys] A new user journey action "Run a script" that allows executing JavaScript in the browser has been added. For more details, consult our [user journey page](configuration/user-journey/create-a-scenario.md#run-a-script)

Dashboards

- [New widget] Users can now add the website's screenshot as a widget. This is done by clicking the star icon on the screenshot's top right corner in Global view.
- [New widget] User journey status which displays the status of a user journey over a given period of time.
