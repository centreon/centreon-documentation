**Parcours Utilisateurs** est le module de surveillance synthétique d'Experience Monitoring.
Une sonde est configurée pour naviguer régulièrement sur votre site, en suivant un parcours prédéfini afin de mesurer divers indicateurs de performance web.

![image](../assets/configuration/user-journey/journey-widget.png)

**Parcours Utilisateurs** vous permet de :

- Surveiller le bon fonctionnement de l'expérience de navigation type et calculer son taux de disponibilité.
- Alerter les gestionnaires du site en temps réel en cas de dysfonctionnement, avec des notifications contenant un rapport d'incident détaillé.
- Mesurer et enregistrer les temps de chargement des pages selon plusieurs critères clés (dont les [Core Web Vitals](https://web.dev/vitals/) de Google).
- Obtenir des recommandations personnalisées pour rendre le site plus rapide.

Nous recommandons de configurer le parcours utilisateur de façon à représenter les actions courantes effectuées par les utilisateurs sur le site.

Consultez notre [article dédié](../configuration/user-journey/user-journey-intro.md) pour en savoir plus sur ce module.
