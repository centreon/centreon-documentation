title: Configurer la Sobriété Numérique
--- 

Si vous disposez de l’option Sobriété Numérique, vous devez indiquer à Experience Monitoring deux informations:

- Où se situent vos serveurs ?
- S’agit-il d’un hébergement Cloud ?

A partir de ces informations, Experience Monitoring évaluera le CO<sub>2</sub> émis par page.

Pour remplir ces informations, rendez vous dans *Configuration* > *Site*
