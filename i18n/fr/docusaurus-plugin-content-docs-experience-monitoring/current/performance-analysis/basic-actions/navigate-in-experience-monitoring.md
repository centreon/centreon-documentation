## Éléments de navigation

Toutes les pages d'Experience Monitoring comprennent les éléments suivants :

1. **un sélecteur de site** (en haut à gauche), permettant à un utilisateur ayant accès à plusieurs sites dans Experience Monitoring de passer de site en site (ex: utilisation d'Experience Monitoring avec une licence Enterprise, utilisation d'Experience Monitoring par une agence ayant accès aux comptes Experience Monitoring de plusieurs clients, etc.).
En cas d’utilisation d'Experience Monitoring en mode “multi-site”, il est également possible de comparer les données de performance en sélectionnant plusieurs sites en même temps, ou encore de construire un tableau de bord personnalisé regroupant des indicateurs de plusieurs sites.

2. **la barre de navigation horizontale** (en haut), permettant de naviguer dans chacun des modules d'Experience Monitoring (”[Parcours Utilisateurs”](../../getting-started/synthetic-monitoring.md), “[Système](../../getting-started/system-view.md)”, “[Real User Monitoring](../../getting-started/real-user-monitoring.md)”, etc.)

3. **un sélecteur de période de temps** (en haut à droite), permettant de modifier à tout instant la période qui est analysée. Cette fonction est importante pour constater l’évolution des temps de réponse d’un site, parfois sur plusieurs semaines ou mois. Par défaut, Experience Monitoring montre les dernières 24h et actualise la page chaque minute afin de remonter les dernières mesures en temps réel.

## Mode multisite

Si votre compte donne accès à plusieurs sites Experience Monitoring — par exemple
dans le cadre d'une licence Enterprise ou en tant qu'agence gérant plusieurs clients — vous pouvez
utiliser le sélecteur de site pour passer de l'un à l'autre ou travailler simultanément sur plusieurs sites.

Le mode multisite vous permet de :

- **Comparer côte à côte les données de performance** de plusieurs sites.
- **Créer des tableaux de bord personnalisés** qui regroupent les métriques de plusieurs sites dans une
  vue unique.

## Page Vue globale

Lorsque vous vous connectez pour la première fois à Experience Monitoring, vous arrivez par défaut sur la page **Vue globale**. Cliquez sur **Configuration** dans le coin supérieur droit pour personnaliser l'affichage de cette page pour un site.
