title: Gérer des tickets
description: Présentation du module Open Tickets permettant de créer des tickets d'incident dans un outil ITSM depuis Centreon Cloud
---

Le module communautaire **Centreon Open Tickets** permet d'intégrer Centreon à un système de gestion de tickets d'incidents (outil ITSM, appelé « provider »).

Lorsqu'un service entre dans un état non-OK, un opérateur peut créer un ticket directement depuis l'interface Centreon :
* depuis le widget **Tableau des ressources** [dans un tableau de bord](../alerts-notifications/dashboards.md)
* depuis le widget **Open tickets** dans [une vue personnalisée](../alerts-notifications/custom-views.md) (legacy).
