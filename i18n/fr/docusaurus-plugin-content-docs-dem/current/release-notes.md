## January 29th, 2026

<details open>
  <summary>Features</summary>

- [User journeys] A new user journey action "Run a script" that allows executing JavaScript in the browser has been added. For more details, consult our [user journey page](configuration/user-journey/create-a-scenario.md#run-a-script)
- [Dashboards] New widget - Users can now add the website's screenshot as a widget. This is done by clicking the star icon on the screenshot's top right corner in Global view.
- [Dashboards] New widget - User journey status which displays the status of a user journey over a given period of time.

</details>

<details open>
  <summary>Enhancements</summary>

- [User journeys] The journey overview is now set to the Hero Time metric by default (instead of Speed Index), which provides a better overview of the different steps.

</details>
