title: Les rapports disponibles
---

Vous pouvez ici prévisualiser les modèles de rapport et obtenir des informations sur leurs paramètres et leurs pré-requis. Les modèles de rapport sont regroupés par le type de données qu'ils contiennent.

| Catégorie de rapport | Type de données |
| --- | --- |
| Rapports de surveillance des activités métier | Données [BAM](https://docs.centreon.com/fr/docs/service-mapping/introduction). |
| Rapports de disponibilité et d'événements | Données [Disponibilité](https://docs.centreon.com/fr/docs/reporting/concepts/#availability) et [Événements](https://docs.centreon.com/fr/docs/reporting/concepts/#event). |
| Rapports de performances | Toutes les mesures. |
| Rapports de stockage | Mesures **Disque**. |
| Rapports de réseau | Mesures **Trafic**. |
| Rapports de virtualisation | Indicateurs liés à la virtualisation. Par exemple, certains de ces rapports contiennent les indicateurs suivants : **CPU-ESX, Memory-ESX, VMcount-ESX, Datastore-usage, Datastore-IOPS, Vm-Cpu-Global, Vm-Memory-Global, Vm-Datastore-Iops-Global, VM-Statistics**. |
| Rapports sur la consommation électrique | Indicateurs qui indiquent le nombre de kWh utilisés et le prix par kWh. |
| Rapports de profiling | Indicateurs tels que CPU, stockage, mémoire et [disponibilité](https://docs.centreon.com/fr/docs/reporting/concepts/#availability). |
| Rapports d'inventaire et de configuration | Informations de débogage : affiche les données de configuration (hôtes, groupes d'hôtes...) qui ont été importées dans MBI |
| Rapports de diagnostic de la base de données | Informations de débogage : affiche les données agrégées de performances et de disponibilité présentes dans la base de données MBI (agrégées par mois ou par jour).  |
