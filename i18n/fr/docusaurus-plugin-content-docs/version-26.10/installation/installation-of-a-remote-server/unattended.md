Pour installer un serveur distant plus rapidement, vous pouvez utiliser un script. Celui-ci exécutera toutes les étapes de l'installation. Vous devrez ensuite enregistrer le serveur distant et le rattacher au serveur central.

## Prérequis

1. Mettez votre système à jour :

   <Tabs groupId="os">
   <TabItem value="RHEL 9" label="RHEL 9">

   ```shell
   dnf update
   subscription-manager register --username my_username --password my_password --auto-attach --force
   subscription-manager repos --enable codeready-builder-for-rhel-9-x86_64-rpms
   ```

   Remplacez **my_username** et **my_password** par les identifiants de votre compte Red Hat.

   </TabItem>
   <TabItem value="Alma / Oracle Linux 9" label="Alma / Oracle Linux 9">

   ```shell
   dnf update
   ```

   </TabItem>
   <TabItem value="RHEL 10" label="RHEL 10">

   ```shell
   dnf update
   subscription-manager register --username my_username --password my_password --auto-attach --force
   subscription-manager repos --enable codeready-builder-for-rhel-10-x86_64-rpms
   ```

    Remplacez **my_username** et **my_password** par les identifiants de votre compte Red Hat.

   </TabItem>
   <TabItem value="Alma / Oracle Linux 10" label="Alma / Oracle Linux 10">

   ```shell
   dnf update
   ```

   </TabItem>
   <TabItem value="Debian 13" label="Debian 13">

   ```shell
   apt update && apt upgrade
   ```

   </TabItem>
   </Tabs>

2. Téléchargez le script :

   ```shell
   curl -L https://download.centreon.com/26.10/unattended.sh --output /tmp/unattended.sh
   ```

## Installation

1. En tant que **root**, exécutez le script avec les options souhaitées. Le script écrit un journal complet, comprenant les éventuelles erreurs, dans `/var/log/centreon-unattended-<date>.log`.

   Voici la commande de base (elle installe MariaDB sans TLS) :

   ```shell
   bash /tmp/unattended.sh install -t central -v 26.10
   ```

   Et voici les options que vous pouvez passer (voir les [exemples](#exemples) ci-dessous) :

   | Option | Description |
   |--------|-------------|
   | `-d <database>` | Base de données à installer. Par défaut, le script installe MariaDB : utilisez `-d mysql` pour installer MySQL à la place. |
   | `--tls enabled` | Installe le serveur central en mode TLS : les connexions à l'interface web et à la base de données sont chiffrées. Sans cette option, le serveur central est installé sans TLS. Notez que sur certains systèmes d'exploitation, les politiques cryptographiques peuvent empêcher le script de s'exécuter correctement. |
   | `-p <password>` | Mot de passe du compte **admin** par défaut de la base de données. Si vous omettez cette option, le script génère un mot de passe et vous indique où il est stocké. |
   | `-s` | Installation silencieuse : le script ne vous demande rien. |
   | `-l <level>` | Niveau de détail du fichier de journal : `DEBUG`, `INFO`, `WARN` ou `ERROR`. |

   Pour afficher la liste complète des options, exécutez :

   ```shell
   bash /tmp/unattended.sh -h
   ```

2. Rendez-vous sur http(s)://\<SERVER_IP\>/centreon (où \<SERVER_IP\> est l'adresse IP de votre serveur) et connectez-vous. Suivez ensuite les étapes d'[initialisation de la supervision](../web-and-post-installation.md#initialisation-de-la-supervision).

3. Une fois le script exécuté, réalisez les [étapes 5 à 8 de la procédure d'installation standard d'un serveur distant](./using-packages.md#étape-5--installation-web).

4. Commencez à utiliser Centreon : suivez notre [guide de démarrage](../../getting-started/welcome.md) pour commencer à superviser vos ressources.
