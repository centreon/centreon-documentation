## Introduction

Vous trouverez dans ce chapitre tout ce qui concerne **Centreon Open Source**.

> Il est important de mettre à jour en utilisant la documentation adéquate de mise à jour et de lire attentivement les
> notes de mise à jour afin d'être au courant des changements qui pourraient impacter votre usage ou votre plateforme
> ou des développements spécifiques que vous auriez fait.

Pour faire des demandes d'évolutions ou signaler des bugs sur les extensions commerciales, vous pouvez vous rendre sur
notre [Github](https://github.com/centreon/centreon/issues/new/choose).

> Retrouvez plus de détails sur la version 24.10 dans notre [post de blog](https://www.centreon.com/fr/centreon-annonce-la-sortie-de-sa-derniere-version-logicielle-centreon-24-10/).

### 24.10.9

Release date: `August 6, 2025`

> With this release, which officially marks the end of the Centreon Monitoring Agent Beta phase, the security of Agent/Poller communication has been reinforced.
> The creation of a new agent configuration via the interface or API now requires a valid authentication token.
> To avoid disrupting configurations already in place (and therefore without tokens) at the time of the update, TLS connections without tokens are still tolerated.
> This will no longer be the case in 25.10: any secure connection without a valid token will be refused by the poller and agent.
> Before migrating to 25.10, you will therefore need to:
> * Generate a token
> * Apply it to the agent configuration on the Poller
> * Apply it to the agent configuration on the Host
> * Export the configuration and restart Engine, as well as the Agent on the Host
> To do this, follow the dedicated step-by-step instructions: https://thewatch.centreon.com/product-how-to-21/how-to-configure-a-token-for-centreon-monitoring-agent-4880

> With this release, which officially marks the end of the Centreon Monitoring Agent Beta phase, the security of Agent/Poller communication has been reinforced.
> The creation of a new agent configuration via the interface or API now requires a valid authentication token.
> To avoid disrupting configurations already in place (and therefore without tokens) at the time of the update, TLS connections without tokens are still tolerated.
> This will no longer be the case in 25.10: any secure connection without a valid token will be refused by the poller and agent.
> Before migrating to 25.10, you will therefore need to:
> * Generate a token
> * Apply it to the agent configuration on the Poller
> * Apply it to the agent configuration on the Host
> * Export the configuration and restart Engine, as well as the Agent on the Host
