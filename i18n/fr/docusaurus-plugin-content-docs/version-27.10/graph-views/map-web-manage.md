Cette page décrit comment effectuer des actions sur vos cartes à partir de l'interface Centreon MAP. Vous pouvez créer deux types de cartes :
- **Cartes standard :** pour visualiser des représentations graphiques de votre infrastructure supervisée.
- **Vues géographiques :** pour afficher les ressources de votre infrastructure sur une zone géographique définie.

> Les options disponibles dans l'interface MAP dépendent des permissions qui vous ont été attribuées par votre administrateur. Consultez la page [Gérer les droits d'accès dans MAP](map-web-access.md) pour plus d'informations sur les privilèges et permissions.

Si le bouton **Ajouter une carte** ou **Ajouter une vue géographique** s'affiche, vous appartenez à un groupe d'accès auquel le rôle de créateur est attribué et vous pouvez créer des cartes.

## Informations sur le statut d'une carte

La page **Map** liste les cartes existantes. Chaque carte affiche le statut le plus critique des ressources et conteneurs qu'elle contient.

## Effectuer des actions sur une carte

Vous pouvez effectuer des actions sur chaque carte standard et chaque vue géographique à laquelle vous avez accès. Suivez ces procédures si vous souhaitez modifier les propriétés d'une carte, la partager ou la supprimer.

### Dupliquer une carte

Cliquez sur le menu **trois points verticaux** en haut à droite de la carte, puis cliquez sur **Dupliquer**.
Une nouvelle carte est automatiquement créée, avec « - copie » ajouté au nom initial.

### Supprimer une carte

Cliquez sur le bouton **corbeille** et confirmez la suppression en cliquant sur le bouton **Supprimer**.

### Modifier les propriétés de la carte

Cliquez sur le bouton **clé à molette** pour modifier les propriétés de la carte et confirmez les modifications en cliquant sur le bouton **Modifier**.

### Partager une carte

Cliquez sur le bouton de **partage** pour modifier les privilèges du groupe d'accès et confirmez les modifications en cliquant sur le bouton **Sauvegarder**.

### Copier l'URL de la carte

Un bouton **Copier l'URL de la carte** est disponible en mode visualisation : il vous permet de partager facilement la carte que vous avez ouverte.
