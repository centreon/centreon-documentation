Centreon Log Management propose une API REST permettant d'interagir avec les logs, les alertes et la configuration du produit. Cette API s'adresse aux développeurs et intégrateurs souhaitant automatiser ou étendre Centreon Log Management.

Commencez par [Démarrer](/api/reference/log-management/centreon-log-management-api.info.mdx) : comment créer un jeton et envoyer votre première requête. La référence de l'API, dans cette section, donne ensuite pour chaque endpoint :

- ses paramètres, et les schémas de sa requête et de ses réponses
- des exemples de code, dans plusieurs langages
- un panneau de requête, pour envoyer des requêtes à l'API depuis la page.
