## API CLM

Centreon Log Management propose une API RESTful permettant d'interagir avec les logs, les alertes et la configuration du produit.

La documentation complète et interactive de l'API est disponible ici :

[Consulter la documentation API Centreon Log Management](https://docs-api.centreon.com/api/centreon-log-management/)

Vous y trouverez :
- La description des endpoints disponibles
- Les méthodes d'authentification
- Des exemples de requêtes et de réponses
- Un outil pour tester les appels API directement depuis l'interface

> Cette API s'adresse aux développeurs et intégrateurs souhaitant automatiser ou étendre les fonctionnalités de Centreon Log Management.
