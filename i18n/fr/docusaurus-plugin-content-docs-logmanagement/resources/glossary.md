## severity

Toutes les requêtes de Centreon Log Management se basent sur le severity number (l'ID de sévérité au format OpenTelemetry). Les libellés de la sévérité utilisés dans Centreon Log Management sont ceux définis par le standard OpenTelemetry. Si votre équipement utilise d'autres libellés dans leur attribut severity_text, ceux-ci seront ignorés. Cela vous permet d'éviter les doublons et entrées incohérentes dans la liste des sévérités.
