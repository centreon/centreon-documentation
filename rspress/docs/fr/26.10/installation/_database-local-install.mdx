<Tab value="Alma / RHEL / Oracle Linux 9" label="Alma / RHEL / Oracle Linux 9">

```shell
dnf install -y mysql-server mysql
dnf install -y centreon-mysql centreon
grep -q '^!includedir /etc/my.cnf.d' /etc/my.cnf || echo '!includedir /etc/my.cnf.d' >> /etc/my.cnf
systemctl enable --now mysqld
sed -Ei 's/LimitNOFILE\s\=\s[0-9]{1,}/LimitNOFILE = 32000/' /usr/lib/systemd/system/mysqld.service
systemctl daemon-reload
systemctl restart mysqld
```

Vous devez obligatoirement définir un mot de passe pour l'utilisateur root de la base de données (vous aurez besoin de ce mot de passe lors de l'[installation web](web-and-post-installation.md)). Il doit comporter au moins 8 caractères, dont des majuscules, des minuscules, un chiffre et un caractère spécial. Récupérez le mot de passe temporaire créé par MySQL :

```shell
grep 'temporary password' /var/log/mysqld.log
```

Modifiez-le ensuite lorsque la commande suivante vous y invite :

```shell
mysql_secure_installation
```

Répondez **yes** à toutes les questions sauf à "Disallow root login remotely?".

</Tab>
