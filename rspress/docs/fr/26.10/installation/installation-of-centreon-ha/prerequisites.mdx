## Dimensionnement

Reportez-vous aux [informations générales de dimensionnement](../prerequisites.md) des plateformes Centreon standard. De plus, vous **devez** avoir au moins 5 Go disponibles sur le VG qui contient la partition **/var/lib/mysql**, sinon vous ne pourrez pas mettre en place la réplication.

## Tableau des flux réseau pour la HA

| Source | Destination | Port/Protocole | Commentaires |
|--------|-------------|----------------|----------|
| Nœud central actif | Nœud central passif | TCP 22 | Pour synchronizer les fichiers de configuration (le flux doit également être ouvert dans le sens passif --> actif) |
| Nœud central actif | Nœud central passif | TCP 5670 | Pour synchronizer les fichiers RRD (le flux doit également être ouvert dans le sens passif --> actif) |
| Nœud DB actif | Nœud DB passif | TCP 3306 | Synchronisation MySQL (le flux doit également être ouvert dans le sens passif --> actif) |
| Nœud DB actif | Nœud DB passif | TCP 22 | Synchronisation MySQL (le flux doit également être ouvert dans le sens passif --> actif) |
| Serveurs centraux + DB + QDevice | Serveurs centraux + DB + QDevice | UDP 5404 | Communication dans the cluster (Multicast) |
| Serveurs centraux + DB + QDevice | Serveurs centraux + DB + QDevice | UDP 5405 | Communication dans the cluster (Unicast)|
| Serveurs centraux + DB + QDevice | Serveurs centraux + DB + QDevice | TCP 2224 | Communication dans the cluster |
| Serveurs centraux + DB + QDevice | Serveurs centraux + DB + QDevice | TCP 5403 | Communication avec le QDevice |

Vous pouvez également consulter le [tableau général des flux réseau](../technical.md#tableaux-des-flux-réseau).
