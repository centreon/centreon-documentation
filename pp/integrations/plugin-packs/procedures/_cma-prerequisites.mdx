### Network flow

Only one TCP flow must be open from the host to the poller.

| Source         | Destination | Protocol | Port | Purpose                                              |
|----------------|-------------|----------|------|------------------------------------------------------|
| Monitored host | Collecteur  | TCP      | 4317 | Configuration retrieval, and OpenTelemetry data flow |
