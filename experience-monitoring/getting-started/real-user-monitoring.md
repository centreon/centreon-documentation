The Real User Monitoring (or RUM) feature allows you to measures a website's performance directly from the browsers of real users. 
To do this, HTML tag is inserted into the code's page to monitor the loading times experienced by users.
The tag is designed to be very light so it doesn't slow down the user's browsing. It is also loaded separately so its own loading times are not taken into account in the metrics collected.

The key difference with [user journeys](synthetic-monitoring.md) is that while the latter checks the performance of a preestablished navigation of the website, RUM measures the experience of real users.

RUM also takes into consideration the browser used, the user's OS and the region of the world from which the website is being accessed.. 
This allows you to determine if 

> RUM records and stores purely technical data that is impossible to identify in compliance with the scope of the the European Union's [GDPR](https://gdpr.eu/).

## Adding the RUM tag to your website

### Obtaining the RUM tag

The RUM tag is automatically generated by Experience Monitoring and can be retrieved from your platform. Go to **Configuration** and click on the **Integrations** tab.

In the **Real User Monitoring** section, click the **Copy RUM tag** button to obtain the tag.

The RUM tag can be manually added to the 'HEAD' section of your website by a developer. Alternatively, if you have a Google Tag Manager account, you can add the tag from there.

Please note that it can take several minutes for the data to appear in Experience Monitoring after installing the tag.

### Using Google Tag Manager

1. Sign in to your GTM account and select the container for your website. Click "Add a new tag."

2. Select "Custom HTML Tag" as the tag type. Paste the script provided into the HTML field. Ensure the script type is correctly set to "JavaScript" if required.

3. Choose when you want the script to execute. You can apply it to all pages or to specific pages depending on your needs. Triggers allow precise control over when the script runs.

4. After configuring the tag and its triggers, save it and use GTM's preview feature to test whether the script works as expected on your site. This lets you see changes in real time without affecting real visitors.

5. Once you've checked everything works correctly, remember to publish the changes in GTM so the script is active on your live site.

Please note that it can take several minutes for the data to appear in Experience Monitoring after installing the tag.
