An unattended installation lets you install a central server by passing all the required settings as options when you run the installation script. The script uses those values to complete the installation on its own, so the process is quick and requires little effort.

This is useful when you need to install several central servers with identical settings, when you install from a deployment tool or CI pipeline, or when you have no interactive access to the target machine.

> An unattended installation always sets up the central server with a local database. To use a remote database, [install the central server from packages](using-packages.md).

   ```shell
   curl -L https://download.centreon.com/26.10/unattended.sh --output /tmp/unattended.sh
   ```

## Installation

1. As **root**, run the script with the options you want. The script writes a full log, including any errors, to `/var/log/centreon-unattended-<date>.log`.

   Here is the basic command (installs MariaDB with no TLS):

   ```shell
   bash /tmp/unattended.sh install -t central -v 26.10
   ```

   And here are the options you can pass (see the [examples](#examples) below):

   | Option | Description |
   |--------|-------------|
   | `-d <database>` | Database to install. By default, the script installs MariaDB: use `-d mysql` to install MySQL instead. |
   | `--tls enabled` | Installs the central server in TLS mode: the connections to the web interface and to the database are encrypted. Without this option, the central server is installed without TLS. |
   | `-p <password>` | Password of the default **admin** database account. If you omit this option, the script generates a password and tells you where it is stored. |
   | `-s` | Silent installation: the script does not prompt you for anything. |
   | `-l <level>` | Level of detail of the log file: `DEBUG`, `INFO`, `WARN` or `ERROR`. |

   To display the full list of options, run:

   ```shell
   bash /tmp/unattended.sh -h
   ```

2. Go to http(s)://\<SERVER_IP\>/centreon (where \<SERVER_IP\> is your server's IP address) and log in. Then follow the
   [initialization of the monitoring](../web-and-post-installation.md#initialization-of-the-monitoring) steps.

3. Start using Centreon: follow our [Getting started](../../getting-started/welcome.md) guide to start monitoring your resources.
