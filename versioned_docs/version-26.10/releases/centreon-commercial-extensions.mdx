## Introduction

You can find in this chapter all changelogs concerning **Centreon Commercial Extension**.

> It is very important when you update your system to refer to this section in order to learn about behavior changes or
> major changes that have been made on this version. This will let you know the impact of the installation of these
> versions on the features you use or the specific developments that you have built on your platform (modules,
> widgets, plugins).
If you have feature requests or want to report a bug, please contact support.

## Centreon MAP

### 26.10.0

Release date: `October 20, 2026`

<details open>
  <summary>Enhancements</summary>

- [MariaDB] Added support for MariaDB 11.8.
- [Viewer] Added a new icon for flapping resources.
- [Configuration] Unified Maps icons, using the icons from Centreon Web.
- [Configuration] Improved the BBDO state synchronization reliability. The default periodic reload was disabled while maintaining a manual sync API and a configuration fallback for emergencies.
- [Metric Link widget] Metaservices can now be used to visualize cumulative inbound and outbound traffic.
- [Server] Expanded broker event queue capacity to enhance overall performance.
- [Server] Replaced the fixed-size BBDO message queue with a dynamic scaling. This prevents message loss while maintaining strict memory usage limits.
- [Viewer] Modernized the resources display and its status indicators to improve readability and align with the product’s design standards.

</details>

<details>
  <summary>Security fixes</summary>

- This release contains security fixes. Details will be available soon on [The Watch](https://thewatch.centreon.com/latest-security-bulletins-64).

</details>

## Centreon BAM

### 26.10.0

Release date: `October 20, 2026`

<details open>
  <summary>Enhancements</summary>

- [Configuration] ACL-restricted users must now select a Business View when creating a Business Activity.
- [Configuration] Added a "Show only top level" filter on the Business Activity configuration listing.
- [Configuration] Added a new simulation mode to the Business Activity configuration page. This allows users to preview the impact of their changes before enacting them.
- [Configuration] The impact-weight selector now shows each word's percentage (e.g. Major (50%)) directly in the dropdown.
- [Configuration] Users can now define custom icons for BAs, making nodes and indicators easier to identify in the Business Activity tree.
- [Configuration] Business Activities can now be configured directly through an interactive dependency tree.
- [UI] Resources now use new, consistent icons across the interface for easier identification.
- [UI] Changed Business Activity Trees' default display type from curve to step.

</details>

<details>
  <summary>Security fixes</summary>

- This release contains security fixes. Details will be available soon on [The Watch](https://thewatch.centreon.com/latest-security-bulletins-64).

</details>

## Centreon MBI

### 26.10.0

Release date: `October 20, 2026`

<details open>
  <summary>Enhancements</summary>

- [MBI] Added support for MariaDB 11.8.
- [MBI] Added tooltips to explain how retention works in the general options form.
