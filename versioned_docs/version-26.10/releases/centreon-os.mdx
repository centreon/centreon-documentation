## Introduction

In this chapter, you can find all the changelogs concerning **Centreon Open Source**.

> It is very important when you update your system to refer to this section in order to learn about behavior changes or
> major changes that have been made on this version. This will inform you about the impact of installing these
> versions on the features you use or the specific developments that you have built on your platform (modules,
> widgets, plugins).

If you have feature requests or want to report a bug, please go to our
[Github](https://github.com/centreon/centreon/issues/new/choose).

## Centreon Web

### 26.10.0

Release date: `October 20, 2026`

<details open>
  <summary>Enhancements</summary>

- [Configuration] (Beta) Added a **Create new poller** shortcut in the top banner that generates a single command line for simple poller deployment via container or packages.
- [API] Added an API endpoint for creating a pollers.
- [API] Added API endpoints to handle global, installed & standard macros.
- [Administration] The **Administration > About** page has been updated for a new look. Many useful links have also been added to it.
- [Agent configuration] It is now possible to configure both connection directions (poller-initiated or agent-initiated) in the same configuration. The user interface has been updated according to this.
- [Agent configuration] When adding an agent configuration, the **CA common name** field is now displayed only in Insecure TLS mode.
- [Authentication] Added "poller" as a new type of authentication token.
- [Agent configuration] CMA can now automatically create hosts when the option is checked in Agent configuration.
- [Configuration] The BBDO protocol version 3.1.0 is now enabled by default for Broker communications.
- [Configuration] The host categories page has been updated with live search, inline enable/disable and a redesigned add/edit form.
- [Configuration] "Resource macros" are now called "Global macros".
- [Configuration] The **Configuration > Commands > Commands** configuration page has been updated.
- [Top Banner] Redesigned the status tiles make the header clearer and easier to read at a glance.
- [Top Banner] The user's profile menu now shows a circular avatar with the user's initials.
- [UI] Resources now use new, consistent icons across the interface for easier identification.
- [UI] Refreshed interface colors: new primary blue, softer table and section headers, and more readable status chips in light and dark modes.

</details>
