## Introduction

In this chapter, you can find all the changelogs concerning **Centreon Open Source**.

> It is very important when you update your system to refer to this section in order to learn about behavior changes or
> major changes that have been made on this version. This will inform you about the impact of installing these
> versions on the features you use or the specific developments that you have built on your platform (modules,
> widgets, plugins).

If you have feature requests or want to report a bug, please go to our
[Github](https://github.com/centreon/centreon/issues/new/choose).

## Centreon Web

### 26.10.0

Release date: `October 21, 2026`

<details open>
  <summary>Enhancements</summary>

- (Beta) Added a Create new poller shortcut to the top banner that generates a single command line for rapid poller deployment via container or package.
- Provided a new modal to generate Poller install command, for Docker and VM.
- [API] Added an endpoint to create Poller.
- [API] Added endpoints to handle Global, installed & standard macros.
- [API] Added examples on medias endpoints.
- [Administration] Improved the About page and added new links.
- [Agent configuration] It's now possible to configure both connection direction in the same configuration. The user interface has been improved according to this.
- [Agent configuration] “CA common name” is now displayed only in Insecure TLS mode.
- [Authentication] Added a new token type: poller.
- [CMA] Host can now be automatically created when option is checked in Agent configuration.
- [Configuration] Enabled 3.1.0 BBDO protocol version by default for Broker communications.
- [Configuration] Refreshed host categories page with live search, inline enable/disable and a redesigned add/edit form.
- [Configuration] Resource macros have been renamed Global macros.
- [Configuration] Reworked commands configuration page.
- [Top Banner] Redesigned status tiles make the header clearer and easier to read at a glance.
- [Top Counter] The user menu now shows a circular avatar with the user's initials.
- [UI] Resources now use new, consistent icons across the interface for easier identification.
- [Web] Refreshed interface colors: new primary blue, softer table and section headers, and more readable status chips in light and dark modes.

</details>

<details>
  <summary>Bug fixes</summary>

- [Administration] API tokens now display correctly after the user who created them is deleted.
- [Configuration] Changes made in a host's Relations tab are now recorded in the logs like other configuration changes.
- [Configuration] Temporary export folders are now cleaned up, preventing disk saturation when generating poller configuration.
- [Export] Fixed encrypted passwords in exported configuration files, which could prevent Broker from starting.
- [LDAP] LDAP contact groups are now removed during synchronization when deleted from the server or excluded by filter changes.
- [Unattended] Fixed missing support of version 26.10.
- [Unattended] Fixed the path to repository files (RPM).
- [Unattended] Pinned stable plugin repositories for Debian unattended installation.
- [Upgrade] Upgrades no longer enable flapping detection or disable service checks on down hosts, so your engine settings are preserved.
- [Web] Deprecation logs are now disabled by default, preventing the log file from growing uncontrollably and filling the disk.
- [Web] Fixed an issue where some actions would fail when Centreon is accessed through a server with a short name.
- [Web] Fixed an issue where the Resource Status CSV export leaked the translation catalog header into empty columns.
- [Web] Fixed broker config export adding an event_script logger that broke connectivity on pollers older than 25.10.03.
- [Web] Fixed connection failures when the database uses a custom port, which was ignored in favor of the default port 3306.

</details>

<details>
  <summary>Security fixes</summary>

- This release contains security fixes. Details will be available soon on [The Watch](https://thewatch.centreon.com/latest-security-bulletins-64).

</details>

## Centreon Collect

### 26.10.0

Release date: `October 21, 2026`

<details open>
  <summary>Enhancements</summary>

- Added alias field to PB_SERVICE_GROUP protobuf message.
- Fixed an issue where icons configured for Business Activities were not showing up properly.
- The broker now writes the full poller configuration in a single block instead of processing it incrementally. Pollers no longer send their configuration to the broker.
- [Engine] Added a PERL NoFork connector to enhance plugins execution and reduce poller CPU consumption.

</details>

<details>
  <summary>Bug fixes</summary>

- Fixed the installation of centreon-engine and centreon-monitoring-agent on hosts where USERGROUPS_ENAB is set to no in /etc/login.defs: the centreon-engine and centreon-monitoring-agent groups are now always created.

</details>

<details>
  <summary>Security fixes</summary>

- This release contains security fixes. Details will be available soon on [The Watch](https://thewatch.centreon.com/latest-security-bulletins-64).

</details>
