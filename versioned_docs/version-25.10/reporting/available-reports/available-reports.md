Here you can preview report designs and get information on their parameters and prerequisites. Report designs are grouped by the type of data they contain.

| Report category | Type of data |
| --- | --- |
| Business Activity Monitoring reports | [BAM](../../service-mapping/introduction.md) data. |
| Availability and Events reports | [Availability](../concepts/#availability) and [events](../concepts.md#event) data. |
| Performance reports | Any metrics. |
| Storage reports | **Disk** metrics. |
| Network reports | **Traffic** metrics. |
| Virtualization reports | Metrics relating to virtualization. For example, some of these report contain the following metrics: **CPU-ESX, Memory-ESX, VMcount-ESX, Datastore-usage, Datastore-IOPS, Vm-Cpu-Global, Vm-Memory-Global, Vm-Datastore-Iops-Global, VM-Statistics**. |
| Electric consumption reports | Metrics that show the number of kWh used, and the price per kWh. |
| Profiling reports | Metrics such as CPU, Storage, Memory, and [availability](../concepts.md#availability). |
| Inventory and Configuration reports | Debug information: shows the configuration data (hosts, host groups...) that has been imported into MBI |
| Database diagnostics reports | Debug information: shows what aggregated performance and availability data is present in the MBI database (aggregated by month or day).  |
