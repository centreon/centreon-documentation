As a reminder, the OSs supported in version 25.10 are the following:

* RHEL/Oracle Linux/Alma Linux 8
* RHEL/Oracle Linux/Alma Linux 9
* Debian 12 (bookworm)

This means that an upgrade is only possible if you were using version 20.10 or later, on RHEL/Oracle Linux/Alma Linux 8 or 9, or Debian 12. For any other version or OS, you will need to perform a [migration](../migrate/introduction.md).
