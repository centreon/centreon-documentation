MBI is a module we developed to help you generate reports in different formats such as CSV. It is an extension of Centreon with its own vocabulary and concepts. This section breaks down the key concepts to understanding Centreon MBI. 

Note that this section expects you to be familiar with the regular Centreon (vocabulary)[glossary.md]

## Jobs

An instance of a report that is to be generated or has already been generated. Jobs can be scheduled to be performed immediately or at a specified time and date. You can also decide if the report is to be generated only once or if it should be generated periodically.

## Job groups

Linked to ACLs, determines who is allowed to access the generated reports.

## Report

End-result of a job, they are summaries of the selected hosts generated by MBI. The appaerance and data shown are determined by the report design which can be selected from our [catalog](available-reports.md) or create your own using BIRT.


## CBIS user
Service user created automatically. Is not a real person but that will obtain data from the resources moniterd by Centreon. Must be granted access to all resources to function properly.

## Availability: 

The metric that measures the amount of time a host has been available. Availability only takes into consideration the time the host has spent in an UP or DOWN status, it does not take into account time spent in an UNREACHABLE state or in DOWNTIME.


## Publication rules

By default, the report is only available on the Centreon user interface, publication rules allow you to make it so the report is sent to specific users every time it is generated.
